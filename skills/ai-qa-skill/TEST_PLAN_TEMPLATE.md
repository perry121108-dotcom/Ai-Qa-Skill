## 六、退出準則（Exit Criteria，對齊 SKILL.md 完成門檻）

```text
[必須] 範圍內功能皆有可執行測試，npm test / pytest 實際通過（附終端機證據）
[必須] 有 LLM 呼叫點：schema 強固性 / 防越獄 / 幻覺誠信 三類測試齊備並通過
[必須] 每個已修 Critical/Major Bug 有對應 Red→Green 回歸測試
[必須] 無法執行者誠實標 Blocked / Not Run，不得偽裝 Pass
[目標] 覆蓋率達標：行覆蓋 ____% / 關鍵模組 ____%
```
